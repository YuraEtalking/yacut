## YaCut — веб‑сервис для создания коротких ссылок и перенаправления по ним на исходные URL.

Доступен веб‑интерфейс (одна страница с формой) и публичное API.

#### Возможности

Создание короткой ссылки для заданного длинного URL.
Поддержка пользовательского варианта короткой ссылки:
не более 16 символов;
если идентификатор уже существует — возвращается ошибка, существующая запись не изменяется.
Автоматическая генерация короткого идентификатора:
6 случайных символов;
используются:
A-Z, a-z, 0-9
если сгенерированный идентификатор уже занят — генерируется заново.
Переадресация при обращении к короткой ссылке на исходный URL.
#### Установка и запуск
Клонировать репозиторий и перейти в него в командной строке:

```
git clone 
```

```
cd yacut
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv venv
```

* Если у вас Linux/macOS

    ```
    source venv/bin/activate
    ```

* Если у вас windows

    ```
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

После изменений в моделях, если такие необходимы:
```
flask db migrate
```
Для применения изменений в базе данных:
```
flask db upgrade
```
Запуск приложения:
```
flask run 
```

#### Стек технологий

Проект реализован на следующем стеке:

Python
- Flask 3 — веб‑фреймворк
- Jinja2 — шаблонизатор (рендеринг HTML-страницы)
- Flask-WTF / WTForms — формы и валидация пользовательского ввода
- Flask-SQLAlchemy + SQLAlchemy 2 — ORM и работа с базой данных
- Flask-Migrate + Alembic — миграции схемы базы данных
- python-dotenv — загрузка переменных окружения из.env
- Werkzeug — WSGI/утилиты Flask (роутинг, редиректы и т.д.)

Инструменты разработки и тестирования:

- pytest (+ pytest-env) — тестирование
- flake8 — линтинг и проверка стиля кода
